# What it is

An **aversion** is a want met by absence: the world states a pattern, and the agent is
content exactly while the pattern binds nothing. It is the general form of what the
[region](/domain/region.md)'s side shapes say per property — a state to avoid that is *not*
a band in one observed property: a debt shape, a marker, any pattern a select can ask.

# One statement is the premise, the grant and the content

`aversion:avoids`, ratified in the world's files: its object is a named node carrying one
`sh:select` — the pattern whose rows mean ENTERED. Stating it grants `aversion:Heeding`
(being told what to steer clear of is the whole of what makes steering meaningful, the same
cut that grants [review](/domain/review.md) by a mandate), derives the want on every rebuild,
and is the text every verdict runs. An agent whose world avoids nothing composes none of
this — absent, not idle.

# Met is the measure reading zero, and that is one text on one engine

The want carries **no `orexis:metWhen`**, deliberately. Its met-test IS its measure: the
ratified select, run with `$this` and `$state` substituted against whichever world is being
judged — the live base for the want's own row, a candidate node inside the planner for a
possible world. One text, one engine, so entered-or-held can never be answered two ways.
[Urgency](/domain/urgency.md) is binary — the four-measures table's third row: between
entered and held there is nothing to be nearer to — and the search never needed a slope to
cross a multi-step exit, because the frontier carries partial steps regardless of score.

# Soft, and beside it the law

An aversion is SHALL NOT: *avoid if we have alternatives*. The search prefers a world where
the pattern binds nothing, picks the cheapest such world where several exist, and where none
is reachable the want stays entered at full heat — a finding on the ask channel, never a
silent shrug. The MUST NOT beside it is not an aversion at all: a ratified `sh:Violation`
shape over a runtime state is LAW, and the planner holds every candidate state to it at
expansion — never-newly-enter, so an agent already inside keeps its exit plans. See
[a-want-met-by-absence](/decisions/a-want-met-by-absence.md).

# The family, and its one member

`aversion:AversionCapability` is the family — steering away from ratified avoided states —
and `aversion:Heeding` its deterministic member: judge by running the pattern. A member that
asked a model where a pattern cannot be written would be a sibling class and one line of
`PROVIDES`, which is rule 2's test met: the *how* of the judging could differ.
