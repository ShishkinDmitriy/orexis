# An amendment endows what it grants, and touches nothing the agent holds

Found live the day arc 4 reached the bench (#202): the world gained the city, the supplier's
derivation gained `market:Bidding`, its authored beliefs gained the buy-side block — and the
running agent crash-looped on the missing terms, because `genesis.birth` correctly refuses to
re-author an existing volume and nothing else could write one. Nothing malfunctioned; the
gap was real. The only remedy was the sovereign discarding the volume by hand, which throws
away everything the agent became — its revised picks, its intention ledger — to deliver two
triples it had merely never been given.

## The unit of novelty is the term

A belief the agent HOLDS is the agent's, revisions included — that is
[a-belief-is-a-pick-within-a-range](/decisions/a-belief-is-a-pick-within-a-range.md)'s whole
point, and an amendment that overwrote a re-picked value would be the sovereign grabbing the
walking-controls. A pair the volume has never held is different in kind: the agent never
picked it, never revised it, and cannot miss it — it is a GRANT in the same sense the mandate
is, and delivering it changes nothing the agent owns. So `endow` (a `Store.endow_graph` the
boot calls after `birth` declines, and after migration — an aged volume's old spellings must
not read as never-held) adds exactly the never-held TERMS, each with its blank-node closure
— an aim is a structure, and half an aim would fail the agent at boot — and skips held terms
whole, whatever their value. The term and not the (subject, predicate) pair, measured: a
beliefs graph has one owner in whatever spelling its era wrote, and pair-keying doubled a
migrated belief the first time endowment met a pre-sweep volume. Every ordinary boot endows nothing and
says nothing; the boot after an amendment logs what arrived, by name.

## What this deliberately is not

- **Not a reset**: nothing held is read, moved or rewritten. The AGENTS.md sentence stands,
  with one addition: an addition is not a reset.
- **Not rebirth**: that remains the explicit act of discarding who an agent became, useful in
  development and never a side effect.
- **Not value migration**: a CHANGED authored value for a held term does not travel — the
  held value is the agent's, and if a sovereign needs to move one, that is review's mandate
  machinery or an explicit rebirth, chosen knowingly. Spelling migration is
  [a-volume-can-be-older-than-the-vocabulary](/decisions/a-volume-can-be-older-than-the-vocabulary.md)'s
  flag and stays orthogonal.

# Seams left open

- **Revocation of a granted block** — an amendment that takes a capability away leaves its
  beliefs in the volume, inert (the module is simply never built). Harmless today; a world
  that wants them gone says so with rebirth. If a gentler removal is ever wanted, it is a
  decision about who owns abandoned beliefs, not a flag on this mechanism.
- **A deleted-by-design belief would be re-endowed** — no machinery deletes single beliefs
  today, so a never-held pair is always a new grant. The day deletion exists, endowment
  needs a tombstone to tell "removed" from "never given", and that day is not this one.
